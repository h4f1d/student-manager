# Student Manager

A lightweight CRUD app for managing student records: add, edit, search and delete. Built with vanilla HTML, CSS and JavaScript — no frameworks, no build step.

## Features

- Create, edit and delete student records (name, group, grade)
- Live search by name or group
- Auto-calculated student count and class average
- State persisted to `localStorage`

## Tech Stack

HTML5 · CSS3 · JavaScript (ES6+)

## Project Structure

```
student-manager/
├── index.html
├── style.css
└── script.js
```

## Getting Started

No dependencies, no build step.

```bash
git clone https://github.com/h4f1d/student-manager.git
cd student-manager
open index.html
```
